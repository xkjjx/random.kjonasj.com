About the app

Lab is being developed for Kevin Jonas Johnson's own accounts. Its Gmail integration supports reading messages and attachments, organizing messages and labels, and composing and sending email through workflows the operator enables. It is not offered as a public email service.

Each account authorizes access directly with Google. The requested Gmail permission, https://www.googleapis.com/auth/gmail.modify, allows reading, composing, sending, and organizing email, including moving messages to Trash. It does not allow immediate permanent deletion that bypasses Trash.

The current setup verifies the connected account and stores authorization credentials for subsequent use. It does not read message contents or send email during account connection. This public page provides app information only; account connection happens through a separate local setup process.

Privacy policy

Last updated: September 5, 2026

Who operates the app

Kevin Jonas Johnson operates Lab for personal use with accounts he controls.

Information accessed

During connection, the app receives Google OAuth credentials and checks the Gmail account's email address using the Gmail profile endpoint. Google may also return mailbox counts with that profile response. The setup process uses the address to verify the intended account and does not retain those counts.

The granted permission allows future operator-enabled workflows to access email addresses, message headers, message bodies, attachments, labels, drafts, and other Gmail data needed to read, organize, or send email. Granting this permission does not by itself start those workflows.

How information is used and shared

Google user data is used to connect the selected accounts and carry out the operator's enabled email-management workflows. Authorization requests and Gmail operations are sent to Google. OAuth credentials are stored in the operator's Amazon Web Services account using encrypted SSM Parameter Store SecureString parameters, with access controlled through AWS IAM.

The current integration does not sell Google user data, use it for advertising, or use it to train generalized artificial intelligence or machine-learning models. It does not send email contents to third-party AI services. Email sent through an enabled workflow is delivered to the recipients selected by the operator.

Lab's use and transfer to any other app of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and retention

OAuth credentials remain in the operator's AWS account until the operator removes or replaces them. A downloaded OAuth client configuration may also be retained in a restricted local folder outside source control. Credentials and authorization codes are not intentionally written to application logs or published on this site.

The current account-connection process does not persist email messages or attachments. Any future workflow that introduces additional storage or data sharing must be reflected in this policy before that use begins.

Revoking access and deleting stored credentials

The account owner can revoke Lab access through Google Account connections. Revocation prevents further authorized access but does not automatically delete copies of credentials held in AWS or local files. The operator can remove the corresponding SSM parameters and local credential files to delete those copies. Disconnecting the app does not reverse email changes already made through it.

This public website

This information page has no sign-in form, analytics scripts, or Gmail connection functionality, and does not receive Gmail credentials or mailbox data. GitHub Pages hosts the page and may process ordinary request information, such as IP addresses, under GitHub's privacy statement.

Changes and questions

This policy will be updated when the integration's data practices change. Privacy questions can be directed to the operator using the contact information below.
